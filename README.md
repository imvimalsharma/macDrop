# macDrop

A file-transfer application for moving files from **Android devices to Mac**.

## 🚀 What It Does

macDrop is designed to make transferring multiple files from an Android phone to a Mac simple and convenient.

## Key Goals

- Android → Mac file transfer
- Multiple-file transfers
- Preserve original file names
- Simple user experience
- Transfer progress tracking

## 🛠️ Technology

The project is primarily focused on Python-based application development and desktop/mobile interoperability.

## 🚀 Getting Started

```bash
git clone https://github.com/imvimalsharma/macDrop.git
cd macDrop
```

Check the project files for the current build and run instructions.
